    How it works

    Three AI agents run an accounts-payable workflow and talk to each other with the A2A protocol: each publishes an Agent Card (/.well-known/agent-card.json) and receives work through JSON-RPC SendMessage. AgentShield sits in the middle, so every call is checked in this order:

    1. Identity: the caller's key must match.
    2. Rate limit: stops loops and floods.
    3. Trusted agent: the target's Agent Card must match the pinned fingerprint.
    4. Permission: least privilege, e.g. the Invoice Reader may never call approve_payment.
    5. Injection scan: rules + a TF-IDF/logistic-regression model on every message, in and out.
    6. PII redaction: PAN, Aadhaar, card numbers removed; bank details only where needed.
    7. Human approval: payments above ₹1,50,000 wait for a person.
    8. Audit: every decision is logged with reasons and timings.

    All data is synthetic. The detector is evaluated on wordings, requested actions and one attack family never seen in training. Source and full results are in the GitHub repository README.
